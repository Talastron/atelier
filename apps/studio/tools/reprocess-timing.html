Reprocess timing

How long background removal takes per item — the one number that decides whether migrating a wardrobe to alpha cut-outs is a coffee break or an overnight job. The model is fetched once (~5MB) and then reused, so the first item is always far slower than the rest; the two are timed separately because only the second matters when multiplied by a wardrobe. Paste image URLs (one per line) or choose files. URLs are fetched through the app's own image proxy, so Firebase Storage links work.
